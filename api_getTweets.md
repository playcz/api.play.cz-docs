# getTweets

Tato metoda vrací seznam tweetů. Všechny Twitter účty musí být registrované v API a jsou stahovány a ukládány v lokální DB.

## Parametry

| parametr | výchozí hodnota | hodnoty | popis |
| --- | --- | --- | --- |
|shortcut|-|shortcut rádia nebo prázdné pro agregovaný feed (rádio musí mít v API napárován účet na Twitteru)|

## Příklad
|/xml/getTweets/cro1|
| --- |
|/jsonp/getTweets/?shortcut=bonton|
