# cf

Tato metoda obaluje některá API Cloudflare

## Parametry

| parametr | výchozí hodnota | hodnoty | popis |
| --- | --- | --- | --- |
|metoda|-|flush|metoda|
|url|-||URL ke smazání z cache - pro metodu flush|
|access_key|-||interní access_key|

## Příklad
|/xml/cf/flush/?url=http://api.play.cz/static/radio_logo/t200/pigy-radio-disko.png&accesskey=95817cbd80|
