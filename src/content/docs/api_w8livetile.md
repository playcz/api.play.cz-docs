# w8livetile

Tato metoda vrací dynamické TILEs pro Windows 8 aplikaci PLAY.CZ (pouze pro interní použití)

## Parametry

| parametr | výchozí hodnota | hodnoty | popis |
| --- | --- | --- | --- |
|tileID|-|shortcut|Tile ID (aktuálně je podporováno jen "playcz")|
|tileNumber|-|tile1 - tile5|Pozice tilu|

## Příklad
|/plain/w8livetile/playcz/tile1|
